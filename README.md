# MusicHub

**Лёгкий музыкальный плеер для Android с современным стеклянным интерфейсом, поиском музыки и офлайн-библиотекой.**

MusicHub — приложение для тех, кто хочет слушать музыку без лишних действий, регистрации и рекламы. Оно объединяет поиск треков, онлайн-воспроизведение, загрузку музыки и удобное управление локальной библиотекой в одном приложении.



---

## ✨ Возможности

### 🔎 Поиск и каталог музыки

* Быстрый поиск треков и исполнителей.
* Бесконечная лента с подгрузкой результатов при прокрутке.
* Меню действий для каждого трека.
* Возможность воспроизведения, скачивания, просмотра текста песни и отправки ссылки.

### 🎧 Музыкальный плеер

* Компактный мини-плеер с обложкой, кнопкой паузы и индикатором прогресса.
* Фоновое воспроизведение музыки.
* Управление через уведомления и экран блокировки.
* Автоматическая пауза при отключении наушников.



### 📥 Офлайн-прослушивание

* Скачивание треков с отображением прогресса в процентах.
* Сохранение обложек вместе с аудиофайлами.
* Возможность сохранять тексты песен.
* Прослушивание скачанной музыки без подключения к интернету.
* Управление загруженными треками: просмотр и удаление.
* Настройка сохранения текстов песен.

### 🏠 Главный экран

Главная страница объединяет несколько разделов:

* **Continue Listening** — история последних прослушанных треков, которая сохраняется между запусками приложения.
* **Downloaded** — библиотека музыки, доступной офлайн.
* **Top Recommendations** — подборка популярных треков с обложками.
* **Best Playlists** — заготовка для будущей системы плейлистов.

<img width="720" height="1528" alt="главная" src="https://github.com/user-attachments/assets/5965c56a-c146-4c06-9f74-111ee36dff38" />

### 📝 Тексты песен

* Поиск текстов через меню трека.
* Проверка описания видео на наличие текста песни.
* Дополнительный поиск через бесплатную базу LRCLIB.

Доступность текста зависит от конкретного трека и наличия подходящего источника.


### 🎨 Дизайн и персонализация

MusicHub использует минималистичный интерфейс с эффектом стекла и плавными анимациями.

* **Liquid Glass** — полупрозрачные элементы с эффектом размытия.
* **Matte** — матовый вариант оформления.
* **System** — оформление в соответствии с системной темой.
* **Light** — светлая тема.
* **Dark** — тёмная тема.
* **OLED** — тема с абсолютно чёрным фоном для OLED-дисплеев.

Выбранные настройки сохраняются между запусками приложения.

В нижней части интерфейса расположена компактная плавающая панель навигации в стиле современного мобильного дизайна.

## 🛠 Технологии

MusicHub разработан для Android с использованием современного стека технологий.

| Технология             | Назначение                                          |
| ---------------------- | --------------------------------------------------- |
| **Kotlin**             | Основной язык программирования                      |
| **Jetpack Compose**    | Создание пользовательского интерфейса               |
| **Material 3**         | Компоненты и оформление интерфейса                  |
| **Coroutines**         | Асинхронные операции                                |
| **Flow**               | Передача и наблюдение за изменениями данных         |
| **NewPipeExtractor**   | Поиск музыки и получение информации об аудиопотоках |
| **Media3 / ExoPlayer** | Воспроизведение музыки и фоновый режим              |
| **OkHttp**             | Сетевые запросы и загрузка файлов                   |
| **DataStore**          | Хранение настроек и истории прослушивания           |
| **Coil**               | Загрузка и отображение обложек                      |
| **LRCLIB**             | Поиск текстов песен                                 |

## 🚀 Основные преимущества

* **Без рекламы.** В интерфейсе приложения не предусмотрены рекламные блоки.
* **Без обязательной регистрации.** Основные функции доступны без создания аккаунта.
* **Компактность.** Размер установочного APK в текущей сборке составляет примерно 23 МБ.
* **Офлайн-режим.** Загруженные треки можно слушать без интернета.
* **Персонализация.** Два варианта оформления и четыре цветовые темы.
* **Сохранение настроек.** Выбранная тема и история прослушивания сохраняются между запусками.
* **Современный интерфейс.** Стеклянные элементы, компактная навигация и плавные анимации.

## ⚙️ Установка и запуск

### Установка готового APK

1. Открой раздел **Releases** в репозитории GitHub, если там опубликована сборка.
2. Скачай APK-файл.
3. Установи приложение на Android, разрешив установку из выбранного источника, если система запросит разрешение.

[Фото: страница GitHub Releases с APK-файлом]

### Сборка из исходного кода

Для сборки потребуются:

* Android Studio.
* Поддерживаемая проектом версия JDK.
* Android SDK.
* Gradle и Android Gradle Plugin, соответствующие конфигурации проекта.

1. Клонируй репозиторий:

   ```bash
   git clone <URL_ТВОЕГО_РЕПОЗИТОРИЯ>
   ```

2. Открой проект в Android Studio.

3. Дождись завершения синхронизации Gradle.

4. Запусти приложение на устройстве или эмуляторе.

Для сборки APK через терминал Windows можно использовать:

```bash
gradlew.bat assembleDebug
```

Команду нужно выполнять из каталога Android-проекта, в котором находится файл `gradlew.bat`.

Готовый debug APK обычно располагается по пути:

```text
app/build/outputs/apk/debug/app-debug.apk
```

Точный путь зависит от структуры проекта и конфигурации сборки.

## ⚠️ Важная информация

MusicHub использует NewPipeExtractor для работы с источниками музыкального контента, в том числе с YouTube.

Доступность аудиопотоков и возможность загрузки могут зависеть от изменений сторонних сервисов. Используй приложение только в соответствии с применимым законодательством, авторскими правами и условиями соответствующих сервисов.

Перед публичным распространением проверь лицензии используемых библиотек и требования платформ, на которых планируется публикация приложения.
